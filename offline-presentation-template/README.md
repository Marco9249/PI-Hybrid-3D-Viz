# نظام التصميم الاحترافي للعروض التقديمية التفاعلية (100% بدون إنترنت)

تم تصميم هذا الدليل والقالب المرفق لحفظ نمط التصميم الاحترافي المتقدم المستخدم في عرض **PI-Hybrid**، مما يتيح لك إعادة تطبيقه بسهولة على أي عروض تقديمية تفاعلية أخرى بشكل كامل دون الحاجة للاتصال بالإنترنت.

---

## 📂 الهيكل المجلد المطلوب
لتشغيل القالب، تأكد من مطابقة هيكل الملفات التالي في مشروعك الجديد:
```text
├── project-folder/
│   ├── assets/
│   │   └── lib/
│   │       ├── gsap.min.js          # مكتبة الحركة GSAP
│   │       ├── ScrollTrigger.min.js # مكتبة التفاعل مع التمرير
│   │       ├── tailwind.min.js      # مكتبة Tailwind مدمجة أوفلاين
│   │       ├── katex.min.js         # محرك الرياضيات LaTeX
│   │       └── katex.min.css        # تنسيق معادلات LaTeX
│   ├── vendor/
│   │   └── fonts/
│   │       ├── outfit-*.ttf         # خطوط العناوين
│   │       ├── space-mono-*.ttf     # خطوط البيانات الرقمية والرموز
│   │       ├── inter-*.ttf          # خطوط النصوص الرئيسية
│   │       └── cairo-*.ttf          # خطوط اللغة العربية
│   ├── core-style.css               # ملف الأنماط والتأثيرات الرئيسي
│   └── index.html                   # ملف العرض الخاص بك (تم بناؤه بناءً على القالب المرفق)
```

## ✨ الركائز التصميمية الأساسية

### 1. الخطوط المحلية (Offline Fonts)
يتم تحميل جميع الخطوط عبر `@font-face` محلياً لتجنب الاعتماد على خوادم Google Fonts:
- **العناوين الرئيسية:** خط **Outfit** المتميز بزواياه الدائرية الأنيقة وحوافه العريضة جداً (font-weight: 900).
- **النصوص والفقرات:** خط **Inter** لقراءة مريحة للغاية ووزن خفيف (font-weight: 300).
- **الرموز البرمجية والأرقام:** خط **Space Mono** للحفاظ على مظهر علمي دقيق.
- **النصوص العربية:** خط **Cairo** المتميز بجمالية الأحرف ودقتها العالية على الشاشات.

### 2. الزجاج البلوري (Glassmorphism)
يتم بناء البطاقات التفاعلية مع الحفاظ على شفافية عالية لخلفية الصفحة المضيئة:
- استخدام `backdrop-filter: blur(35px)` مع حد خفيف جداً شبه شفاف `border: 1px solid rgba(255,255,255,0.05)`.
- إضافة ظل غائر داخلي `inset 0 0 20px rgba(139,92,246,0.1)`.
- زيادة حجم البطاقة وتغيير لون الحدود بسلاسة تامة عند التمرير بالماوس (`transition: all 0.55s cubic-bezier(0.19, 1, 0.22, 1)`).

### 3. التفاعل والحركات الدقيقة (Micro-animations)
- **مؤشر الماوس المخصص (Custom Cursor):** إضافة حلقة ملاحقة (`#cursor`) ونقطة مركزية حادة (`#cursor-dot`) تتفاعل وتكبر عند الوقوف فوق أي عنصر قابل للنقر.
- **التمرير الانسيابي (Scroll Reveal):** استخدام GSAP + ScrollTrigger لإظهار العناصر عند تمرير الصفحة لأعلى بتأثير تلاشي وتحرك خفيف لأعلى (`opacity: 0` و `y: 50` إلى الوضع الافتراضي).

## 🚀 كيفية الاستخدام والتطبيق
1. انسخ مجلد `assets` و `vendor` إلى مشروعك الجديد.
2. ضع ملف الأنماط `core-style.css` في نفس مجلد ملف الـ HTML الخاص بك.
3. استخدم هيكل الكود الموجود في `presentation-template.html` كبداية لتصميم صفحتك.
4. لتخصيص محتويات إضافية، اتبع نفس الهياكل البرمجية للبطاقات لضمان عدم تلف التنسيق البصري.
