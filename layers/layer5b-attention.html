Attention Mechanism Engine

Attention(Q,K,V) = softmax(Q·Kᵀ / √d_k) · V
d_k = 420, Scale = 1/√420 ≈ 0.0488

The dot-product measures similarity between the query (what we seek) and key (what we have), generating probabilistic weights to extract precise values.

⚠ The Complexity Paradox ⚠

Adding Self-Attention severely degraded performance (RMSE spiked from 19.53 to 30.64).

Why? The input features are strictly governed by deterministic solar physics (e.g., Solar Zenith Angle). Forcing a 529K parameter dense network to probabilistically "re-learn" established physical laws introduces catastrophic noise.
