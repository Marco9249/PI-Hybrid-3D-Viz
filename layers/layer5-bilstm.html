Forget Gate (f_t)

Decides what information to discard from the cell state. A sigmoid layer outputs values between 0 (forget entirely) and 1 (keep entirely). In solar forecasting, this allows the network to forget stale weather patterns that no longer apply.

f_t = σ(W_f · [h_t-1, x_t] + b_f)
